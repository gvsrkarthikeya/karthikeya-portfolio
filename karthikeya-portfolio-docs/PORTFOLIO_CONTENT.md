# Portfolio Content Inventory

This file separates confirmed profile information from content that
still needs user review.

## 1. Professional summary --- placeholder

-   [X] years of total professional experience.
-   Experience 1: [Company 1] --- [Role 1] ([dates]).
-   Experience 2: [Company 2] --- [Role 2] ([dates]).
-   Skill 1, Skill 2, Skill 3, Skill 4 (replace with real skills and
    honest proficiency levels).

## 2. Experience/project themes --- placeholder

-   Project 1: [one-line generalized description]. Contributions:
    [Contribution 1], [Contribution 2]. Technologies: [Skill 1],
    [Skill 2].
-   Project 2: [one-line generalized description]. Contributions:
    [Contribution 1], [Contribution 2]. Technologies: [Skill 2],
    [Skill 3].

Do not publish confidential system details, internal URLs, proprietary
screenshots or non-public source code.

## 3. Education

-   Education 1: [Degree], [Institution], [dates].

## 4. Personal interests

-   Interest 1, Interest 2 (include only if wanted on the public site).

## 5. Missing information to collect

-   Preferred public display name.
-   Exact professional headline.
-   Employment dates and exact job titles.
-   Approved public project descriptions and measurable outcomes, if
    any.
-   Education degree title and dates.
-   Public email address.
-   LinkedIn URL.
-   GitHub username/profile URL.
-   Resume PDF, if desired.
-   Which real photo and avatar versions are approved for publication.

## 6. Content rules

-   Do not fabricate metrics, responsibilities, dates, awards or links.
-   Use concise, evidence-based descriptions.
-   Distinguish personal contributions from team outcomes.
-   Do not claim advanced expertise in technologies the user described
    as beginner-level.
